Inbox Coupon Assistant

What leaves this machine

Coupon extraction and chat send the relevant text of your promotional emails — subject, sender and body — to the LLM provider you select below, using your own API key and account. Nothing is sent anywhere else: there is no backend for this extension and no telemetry.

Gmail is read directly by your browser through your own Google Cloud project. Coupons, chat history and sync state stay in this browser profile.

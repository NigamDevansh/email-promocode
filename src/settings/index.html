What leaves this machine

Relevant Promotions email text is sent directly to the provider you choose, using your own API key. When you chat, active coupon details, your question, and up to 10 recent chat turns are also sent to that provider. The extension stores its API key, coupons, and chat history only in this browser profile; it has no backend or telemetry.
